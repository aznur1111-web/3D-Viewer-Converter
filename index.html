Output formats
GLBSTLOBJ
Conversion notes. STL keeps triangle geometry but not materials or textures. OBJ exports geometry and does not create an MTL material file. CAD feature trees, editable sketches, and exact NURBS surfaces are not retained.
Local processing. Conversion runs in the browser. The app downloads the result directly; no conversion server is used.
