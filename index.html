Fig 3. · Output format

Best general-purpose choice. Produces one binary file and can preserve supported materials and textures.

Select a supported model to enable export.
Output formats
Conversion notes. STL, OBJ, OFF and AMF keep triangle geometry only (3MF also keeps per-object colours); point clouds export to PLY or GLB. Models are exported in their original coordinates and units, never re-centred. CAD feature trees, sketches and exact NURBS surfaces are not retained; CAD output is a tessellated mesh.
Local processing. Conversion runs in the browser. The app downloads the result directly; no conversion server is used.
